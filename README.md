# Yoga/Break Timer — Tech.chebur.shop
Это приложение для управления рабочим временем и напоминаний о необходимости регулярной разминки. Оно помогает поддерживать фокус, не забывая при этом о здоровье спины и глаз во время работы за компьютером.

🧘‍♂️ Основные функции
Цикличный таймер: Автоматическое переключение между рабочим циклом (60 минут) и временем для разминки (5 минут).

Гибкое расписание: Возможность выбрать конкретный день недели для активации разминки или сделать её ежедневной.

Геймификация: Счетчик Bio-Score, который увеличивается после каждой завершенной разминки.

Интерактивный оверлей: При наступлении времени разминки экран блокируется, запуская обучающее видео и список рекомендаций.

Двуязычный интерфейс: Поддержка русского (RU) и немецкого (DE) языков.

Аудио-сопровождение: Выбор сигнала оповещения и возможность включить фоновую релакс-музыку.

🛠 Технические особенности
State Management: Использование localStorage для хранения прогресса, текущего режима (работа/отдых) и настроек пользователя.

DOM-манипуляции: Динамическое изменение текста и упражнений в зависимости от выбранного языка.

Browser Notifications: Использование API уведомлений для напоминаний о начале перерыва.

Media Handling: Автоматическое управление воспроизведением видео и аудио с учетом политик браузеров по ограничению автозапуска.

🚀 Настройка и использование
Развертывание: Разместите файлы index.html (или основной файл проекта) на вашем сервере.

Медиа-файлы:

Убедитесь, что в корне проекта присутствуют файлы: video.mp4, gong.mp3, digital.mp3, bowl.mp3.

Фоновая музыка подгружается из внешнего источника (можно заменить на локальный файл в переменной MUSIC_URL).

Персонализация: Выберите предпочитаемый сигнал оповещения и день недели для тренировок в настройках интерфейса.

Обратная связь: Если вам нужно вернуться к делам раньше срока, используйте кнопку «Вернуться в суету» (она также засчитывает прогресс, если разминка была завершена).Chebura-Potagushka
